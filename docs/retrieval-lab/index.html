How many chunks, which search, which chunking: measured

The managed Data Library (section-aware chunks, 512-token max, 0 overlap, hybrid search) hides top-k. This lab rebuilds the same policy corpus locally and varies what the platform doesn't expose. 24 labeled questions: 12 in the policies' own words, 12 paraphrased to avoid them.
