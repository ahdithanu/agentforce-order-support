Acme Order Support · voice

Talk to the agent

The voice variant of the Acme agent, running on Agentforce. Open the chat in the bottom-right corner, tap the microphone, and allow microphone access. You can also type.

The voice demo isn't reachable right now (it runs in a time-limited Salesforce trial org). See the recorded conversations on the main page.

Try saying

  1. Where's my order?It asks for the order number, then the email, reads both back, and only checks them after you say yes. Use order A ten oh one and jamie at example dot com. The answer comes back as "A, ten oh one has shipped with UPS and should arrive on October first."
  2. How much is express shipping?Answered from the shipping policy: "Express shipping costs fifteen dollars."
  3. Can I put merino wool in the dryer?Answered from the care policy.
  4. I'd like to talk to a person.Hands off to the service queue (nobody is staffed in this demo).

What's different from the text agent

RepliesOne or two short sentences, one question at a time, no lists or links.
Numbers and IDsSpoken form: "A, ten oh one", "September thirtieth", "six ninety-five".
Confirmation in codeOrder number, then email, then a read-back. The verify tool only exists after you say "yes": 3/3 live runs, up from 1/3 when it was only an instruction.
RoutingEinstein HyperClassifier router: 29/30 on the routing set at about 240 ms, versus about 700 ms for the default.

Measured in the project's voice-readiness audit: replies over three sentences 2 → 0, hard-to-speak digit strings 7 → 0. Phone-number (telephony) wiring would be the next step and is done in Agent Builder.
